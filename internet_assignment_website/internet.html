Part 1: Internet Technologies

The Internet is a worldwide network of connected computers and devices. When we visit a website, many different technologies work together to move information from a server to our device.

🌐

How the Internet Works

When you enter a website address, your device uses the Domain Name System (DNS) to find the server associated with that name. Your request is broken into small packets of data. Routers move those packets across networks until they reach the server. The server sends information back, and your browser puts the pieces together to display the webpage.

📡

Internet Service Providers (ISPs)

An Internet Service Provider, or ISP, is a company that connects customers to the Internet. The ISP may deliver the connection through fiber, cable, DSL, cellular networks, or other technologies. Your ISP gives your home or device a path to communicate with computers and services around the world.

🧭

Web Browsers

A web browser is an application used to access websites. Browsers such as Chrome, Safari, Firefox, and Edge request webpage files from servers and interpret HTML, CSS, and JavaScript so that people can see and interact with the page.

🔎

Search Engines

A search engine helps people find information on the Web. Search engines discover webpages, organize information in large indexes, and use algorithms to return results related to a user's search. Examples include Google, Bing, and DuckDuckGo.
